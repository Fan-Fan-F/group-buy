# Group Buy · 拼团系统

社交电商拼团玩法的完整演示：开团 → 邀请 → 成团发货 / 超时流团退款。

## 功能

- **拼团商品广场**：拼团价 vs 单买价对比、成团人数要求、商品卖点
- **发起拼团**：成为团长，团卡片展示成员头像位（空位为 ?）
- **参团**：加入别人的团（预置了一个差 1 人的演示团）
- **成团倒计时**：实时 mm:ss，超时自动流团并提示退款
- **状态机**：`ongoing → success`（人齐自动成团）/ `ongoing → failed`（超时）
- 成员列表、我的拼团、localStorage 持久化
- 演示工具：一键「模拟好友参团」

## 运行

浏览器直接打开 `index.html`。
